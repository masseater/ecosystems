# @r_masseater/textlint-rule-preset-ja

This workspace is a textlint preset that checks the owner's way of writing Japanese. `yomiyasu`, ported from yomiyasu, points out hard-to-read Japanese. `no-taigendome` bans sentences that end in a noun after a comma. `no-ni-aru-file` bans a sentence that says a topic is in a file with the verb phrase "ni aru".
